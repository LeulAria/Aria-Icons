# Reporting Security Issues

Aria Icons is dedicated to the responsible disclosure of security vulnerabilities in the website, public API, CLI, and MCP server.

Please **do not** open a public GitHub issue to report a security concern.

Instead, report it privately through a [GitHub security advisory](https://github.com/LeulAria/Aria-Icons/security/advisories/new).

Include:

- What is affected (website at [icons.leularia.com](https://icons.leularia.com), `/api/v1`, `/api/mcp`, or the `aria-icons` npm package)
- How to reproduce it
- The impact you believe it has

Thank you for helping protect the people who use Aria Icons.
