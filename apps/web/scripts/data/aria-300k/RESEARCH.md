# Aria Icons: 300k gap research, open-source SVG families not yet in Aria (2026-10-08, rounds 1 + 2)

**Verified total: 300,147 new unique SVG icons across 621 families. The 300,000 target is reached (by 147).** Round 1: 161,876 icons in 200 families. Round 2: 138,271 icons in 421 families, counted with a stricter dedupe. Excluding copyleft families (GPL/LGPL/AGPL/CC-BY-SA/MPL/EPL): **148,605**.

Baseline checked: `LeulAria/Aria-Icons` `main` and the PR #11 branch `cursor/add-oss-icon-families-3cf0` (identical `apps/web/src/lib/icon-sets.ts`; PR #11 merged 2026-10-08 09:37 GST). I read it remotely and did not change anything. The overlap pool was the 338 vendored set JSONs (661,522 icons, 453,995 unique geometries) plus all of `@iconify/json` 2.2.540 (244 collections). I assumed every Iconify set is already in Aria. No posts, likes, or replies were made on X.

## How "verified" was counted

- **Real files only.** I streamed every source as a tarball (GitHub codeload at HEAD, or the latest npm tarball) and counted the actual `.svg` files in it. Marketing numbers were ignored.
- **Geometry signature.** Each file got a signature: its sorted, normalised path `d` data plus basic-shape attributes, rounded to 0.1, with colours ignored. An icon only counts as *new* when its signature is in neither the Aria pool nor Iconify, and no larger candidate already claimed it. Candidates were processed largest first and each geometry was counted once overall.
- **Theme packs** (freedesktop layout) went through Aria's own rule: one icon per basename (colour vs symbolic), preferring scalable, then 22/24/32/48/16. Symlinks were ignored.
- **Flat sets.** Byte-identical copies were removed. **Size masters (16/20/24/32…, s/m/l) were collapsed to one per icon and style.** Dual-format folders (raw plus optimised, `src` plus `dist`) were cut down to a single folder.
- **Raster check.** Every new icon whose name matches an Iconify icon was rendered at 48 px and compared with all its Iconify namesakes. Icons with IoU > 0.9 were removed (1.7k in total). Flag sets were skipped here, because all rectangular flags look the same as an alpha mask.
- **Licence.** I only counted MIT, Apache-2.0, ISC, BSD, CC0, public domain, CC-BY, CC-BY-SA, OFL, GPL/LGPL, MPL-2.0 and EPL-2.0. Sets with no licence, NC/ND terms, a proprietary licence, or that look like repackaged paid sets are listed separately and **not counted**. A licence that comes only from `package.json` or the README is marked as such.
- **Unknown stays unknown.** Anything I could not count (repo too large, archive failed, no SVG source) is left out of the total.

## Counted families: round 2

Round 2 adds **138,271** new unique SVGs in **421** families (61,210 non-copyleft, 77,061 copyleft). By source: Pling / OpenDesktop 67,629, GitHub / other 31,920, npm 31,283, GitLab 3,454, Kenney 1,591, Wikimedia Commons 1,209, OpenGameArt 721, Codeberg 464.

**Round-2 method.** Everything from round 1 applies (real `.svg` files from downloaded archives, geometry signature with colours ignored, theme packs one icon per basename preferring scalable, then 22/24/32/48/16, flat sets with byte copies removed and size masters collapsed, and the same licence bar). Round 2 adds two things:
- **Full raster near-duplicate check.** Every candidate icon was rendered at 64 px and fingerprinted (16×16 alpha silhouette, 16×16 edge map and an aspect bucket). It was dropped if it came within Hamming ≤7 (silhouette) and ≤32 (edges) of any of the ~1.0M Aria/Iconify icons, any round-1 icon, or any icon from an earlier-committed round-2 family. This applies to all icons, not just name matches, so it is stricter than round 1. Flag sets skip the silhouette test.
- **Copy rule.** A flat set with ≥20 icons where more than 40% are already in Aria/Iconify (by geometry or raster) is rejected as a copy. Each family also needs at least 20 new icons. Families were committed largest first.
- For comparison only, the same 421 families counted with round 1's geometry-only dedupe would give 295,343. The headline uses the strict number.
- **Pling licences.** A Pling family counts when the author set a licence on the Pling item, or when the archive ships a LICENSE/COPYING/README licence text (marked "licence file in archive"). Pling uploads for deepin-icons-2022, deepin-plus-all and Dracula icons carry an author-set licence field (AGPL/GPL), unlike the GitHub copies listed in round 1's caution tier.
- Wikimedia Commons families use only files whose own licence is PD, CC0 or CC-BY. CC-BY-SA, GFDL and LGPL files are counted as separate "[share-alike files]" families.
